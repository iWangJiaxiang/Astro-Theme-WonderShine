# 创作中心保存方式

用户已授权实施。本轮不提交、推送或合并项目仓库。

## 行为
- 持久化 Git 工作区（App / Node）支持本地保存和 Git 分支保存。
- 分支保存先保留本地文件，再将本次文件快照提交到独立 `studio/save-*` 分支。当前 HEAD、index 和其他草稿保持不变；同一文件复用分支。
- 分支提交保留在本地，不自动推送或创建 PR。可用 Git 工具推送该分支、创建 PR。
- 普通磁盘部署仅提供本地保存；无持久化工作区的在线 Git 部署明确提供原有远端保存，不伪装本地保存。
- 保存按钮带下拉，工作区和用户隔离的默认偏好；自动保存使用当前选择。正文、动态、话题及设置共用规则。
- 本地已保存但分支失败时返回最新 revision 和未完成状态，允许重试，不误报成功。
