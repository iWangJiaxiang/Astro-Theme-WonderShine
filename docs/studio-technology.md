# Creator Studio 技术选型与验收

本轮以仓库初始化和表单可用性为范围，保留同一套 React 业务界面在 Web、桌面和移动端使用。业务处理仍在 TypeScript；Tauri 只提供文件、网络和系统窗口能力。

## 已采用的组件与职责

| 需求 | 选择 | 边界 |
| --- | --- | --- |
| 界面与状态 | React；已有 signals 适配层继续承接迁移组件，新 App 页面使用 React hooks | 修复稳定 ref 回调，不在本轮重写所有编辑器 |
| 本地文件夹 | `@tauri-apps/plugin-dialog`、`tauri-plugin-dialog` | 系统目录选择器授权；桌面原地编辑，不拷贝仓库 |
| 授权跨重启保留 | `tauri-plugin-persisted-scope`，启用 `protocol-asset` | 同时恢复文件访问和图片预览权限，不开放全盘通配权限 |
| Git | `isomorphic-git`，注入文件和 HTTP 适配器 | 离线保存/提交，显式同步；不依赖 GitHub 专有 API |
| 内容编辑 | Vditor + Markdown 源码与预览 | 编辑器资源随 App 打包，离线可用；内容服务复用已有 portable core |
| 表单和弹窗 | 语义化 HTML、原生 `dialog`、现有 CSS tokens | 共用标签/控件布局；抽屉和弹窗有独立滚动容器 |
| 图标 | 已有统一 SVG Icon 组件 | 当前图标数量小且离线可用；不引入整套动态图标注册表 |
| 回归与视觉验收 | Puppeteer、真实 macOS WebView、Node/tsx 测试 | 沿用现有工具链；截图检查补充尺寸、遮挡、标签重叠断言 |

现阶段没有必要为这些问题整体替换 UI 框架。若后续加入复杂的键盘 combobox、菜单嵌套或可访问拖拽，可针对具体交互评估 React Aria/Radix 等无样式组件；引入前确认键盘、读屏、移动端和包体积收益。对于图标扩展，同样优先静态按需导入，不按字符串加载整个图标库。新依赖应解决已复现的问题，并有对应的行为或截图验收。

## Studio 会话与 API 边界（开发约定）

`apps/studio/src/api.ts` 导出的 `session.value` 可赋为 `null` 或固定结构的会话记录：`identity`、字符串 `csrf`、有限数值 `expires`；`identity` 只含字符串 `id`、字符串 `name` 和取值为 `password` / `oidc` 的 `method`。这些字段支持直接赋值，也支持整体替换会话或身份记录。输入按字段复制到边界私有数据，读取返回边界拥有的 proxy；未替换的记录保持 proxy 引用稳定，外部原始输入对象的后续修改不影响当前会话；赋回当前 owned proxy 则保留原引用。

结构输入只接受普通对象或空原型对象的完整自有数据属性；未知字段、accessor、缺失字段或非法值会被拒绝。proxy 允许读取、枚举和属性描述符查询，但拒绝定义属性、删除属性、替换原型和禁止扩展等结构改写；不能以冻结或反射改写绕过字段校验。`Object.assign` 是逐字段写入，不是原子事务。被替换下来的 proxy 已脱离当前会话，仍可作为独立记录修改；重新赋回时会复制成新的 owned proxy，不恢复旧引用的所有权。

`authenticationEpoch`、`identityEpoch` 和 `apiTransportGeneration` 是只读、可响应追踪的数值 ref，通过 `.value` 读取。对当前会话，`csrf`、`expires`、身份 `id` / `method` 的变化，以及会话或身份记录替换，推进认证代次；身份 `id` / `method` 或登录存在性变化同时推进身份代次。直接修改当前身份的 `name` 只发布更新，不推进这两个代次。标量字段的同值赋值、赋回当前 owned proxy 或在已为 `null` 时再次赋 `null` 不产生变更；字段值相同的新记录仍属于替换。`setApiTransport` 每次调用均推进传输代次，包括设置相同函数；代次耗尽时则拒绝调用。状态与代次在写入时同步生效，通知可被 signals 的 `batch` 合并；不能把通知尚未送达理解为旧会话或旧传输仍有权限。

API 的 401 仅在非登录请求、仍有当前会话且请求捕获的认证代次和传输代次仍有效时设置 `reauthentication`；这项判断不以 locale 代次作为认证依据。GET 另有会话/语言作用域与传输过期检查，因此语言切换仍可能使旧 GET 被拒绝。PUT 等写请求不会仅因会话或语言作用域改变而丢弃返回结果，但传输更换仍可使其返回过期错误（logout 有专门例外）；返回结果本身不授权旧组件继续更新当前界面。写请求不会自动重放，客户端拒收响应也不表示服务端写入已撤销。

已挂载的 `SettingsView` 将当前身份、传输、设置组与内容语言绑定到该实例。同一身份、同一传输下的认证代次变化保留已加载的表单值、baseline、revision 及已有标签页草稿，但使旧请求失去更新当前表单的权限；中断的主设置读取和可选内容读取分别等待显式重新加载或重试，不自动覆盖现有编辑。身份或传输代次改变则停用旧实例，移除其字段与子组件弹层；“返回工作台”沿用 App 既有的进行中操作阻拦与未保存确认，不自动恢复或保存设置。

若保存 PUT 已发起后跨越认证或实例归属边界，旧结果不再被采纳为当前表单的保存结果；请求结束也不会自动解除该实例的“保存结果无法确认”状态。再次保存保持禁用，直至仍具权限的实例在请求结束后经确认重新加载，或该实例实际卸载；卸载只终止此实例的状态，不证明服务端未写入，也不是建议的恢复手段。客户端不采纳响应不等于服务端回滚。跨实例同 key 的草稿归属与恢复仍未解决，不能由本轮 mounted-instance 保护推导安全恢复保证。

以上是当前进程内的固定 schema 与会话边界，不是恶意 JavaScript sandbox，也不保证任意插件兼容或持久草稿归属。该边界与 API 接入已完成源码审查，运行时验证仍待远程 CI；不据此宣称 Settings 集成验收或跨实例同 key 草稿恢复问题已解决，也不扩展下文历史验收结果。

## 分轮修复

第一轮的三个优先问题：

1. 初始化缺少本地目录入口：增加本地文件夹、远程 URL 和已有 Studio 服务连接。仓库分支、origin、作者信息自动读取，令牌仅保留在当前会话。
2. 表单响应式布局不稳定：修复编辑器按钮挤压、扩展字段按钮换行和手机媒体库侧栏占宽；窄屏目录树置顶，中等宽度的编辑器标题与操作行分开排列。
3. React 引用生命周期导致白屏：缓存同一 ref 的回调，避免暴露对象反复挂载触发更新循环，加入 StrictMode 回归。

第二轮复看截图后的三个问题：

1. 手机首次启动默认进入不可用的本地目录模式：改为可直接粘贴远程仓库地址。
2. 上传保存位置的标签与选项重叠：切为单列时同时重置 grid row。
3. 英文界面自动保存的关闭选项仍是中文：复用已有 Off 翻译并增加切换语言断言。

第三轮检查初始化和新文章：

1. 新远程仓库不再硬编码 `main`；分支留空时跟随远端 HEAD，下载成功后保存实际分支。本地目录和已保存工作区继续严格检查分支。
2. 克隆使用现有 Git 事件显示阶段和阶段百分比，网络响应逐段交给 Git。连接阶段没有虚假百分比；失败后清除进度并允许重试。
3. 文章创建入口、编辑器默认值和共享内容服务统一使用完整 ISO 发布时间，避免本地午夜和 UTC 日期边界造成意外延迟发布。已有日期、精度和时区保持原样，显式填写的未来日期仍用于定时发布。

每轮通过后清理该轮生成截图。最终只保留最后一轮的页面、弹窗与 App 初始化截图；测试报告说明覆盖范围，不把一次截图等同于所有运行状态都已验证。

## 验证边界

- 表单审计使用临时示例站点，覆盖登录、工作台、七组全局设置、文章/动态/话题/合集编辑器、页面专属配置、引用/话题/模板/删除/AI/图片弹窗、语言创建与媒体库。
- 主审计尺寸为 1440×1000、1024×768、390×844。App 额外覆盖本地选择/取消、远程连接、提交设置、客户端 API、工作区同步及英文和移动 UA。
- macOS 实测使用 AppData 外临时 Git 仓库和真实 WebView、fs/HTTP/Git，验证原地保存、离线提交、AI 草稿和重启后的图片读取；AI 服务为回环测试桩，无真实计费请求。
- 系统目录弹窗本身没有自动点击测试；测试专用 Rust setup 模拟的是同样的目录授权。普通 App 不包含该测试行为。
- 未进行 Android/iOS 真机验收、商店签名或发布。暂不支持作为本地根目录打开 worktree/submodule、SSH 内置同步或可视化解决合并冲突。

## 第三轮验收结果

2026-11-01：188 项单元测试、类型检查、App/服务端构建、完整浏览器与 Astro 集成、React StrictMode、两种 macOS 工作区验收通过。最终保留 144 张 Web 表单截图和 33 张 App 截图，覆盖 48 个 Web 场景及初始化、失败重试、真实临时 Git 克隆进度等状态。截图脚本在切换场景前明确关闭弹窗，避免搜索框 Escape 只清空查询而留下遮罩。布局检查未发现重叠、越界或控件挤压。

本轮独立审查补充修复了 Git 鉴权响应未消费时的资源释放；错误响应和重定向在返回/拒绝前主动取消 body，正常下载保留流式读取。
